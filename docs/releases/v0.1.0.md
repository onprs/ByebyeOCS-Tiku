- 提供本地 OCS 题库服务，可在网页中复制题库配置并接入 OCS 网课助手。
- 支持 OpenAI 兼容、Anthropic、Google 和 Ollama 等模型服务，提供常用厂商预设与连通性测试。
- 支持图片题目识别，以及由独立模型将图片转述为文字后作答。
- 提供 Agent 答题模式，可检索历史题目辅助作答，失败时自动回退到普通答题。
- 支持模型能力识别、手动标注和在线更新模型能力数据。
- 提供答题记录、答案详情、调用耗时、Token 用量及每日统计。
- 提供 Windows、Linux、macOS 的 x64 和 ARM64 单文件程序，下载后即可运行并访问网页控制台。
